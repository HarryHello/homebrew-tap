# homebrew-tap

Homebrew tap for [BA Click](https://github.com/HarryHello/ba-click-mac) — the native macOS **Blue Archive click effect + cursor trail**.

## Install / 安装

```
brew install --cask harryhello/tap/ba-click
```

Upgrades go through `brew upgrade --cask ba-click`. The cask is regenerated from the release DMGs by `tools/update-homebrew-tap.sh` in the main repo.

[BA Click](https://github.com/HarryHello/ba-click-mac) 的 Homebrew tap——**碧蓝档案点击特效 + 鼠标光迹** 的 macOS 原生版。升级用 `brew upgrade --cask ba-click`；Cask 由主仓库的 `tools/update-homebrew-tap.sh` 在每次发版后自动生成。
